# arabic-revision

Flashcards and quick quizzes for revising spoken Palestinian Arabic, one lesson at a time: an unofficial study aid for
the Intensive Palestinian Arabic Speaking Course at [Palestine House](https://palestinehouse.org/), taught by Alaa
Sonjoq. Works offline and keeps progress on the device only.

- Preview: `python3 -m http.server 8417`, then open the address it prints.
- Tests: `node --test` (Node.js 22 or later).
- Changing a page file needs a new VERSION in sw.js; `node --test` gives the value.
